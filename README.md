# Давинчи — автоответчик для бота знакомств

Django REST Framework + Telethon + OpenAI.

Юзербот читает анкеты, которые присылает **@leomatchbot (Дайвинчик)**, отправляет их в OpenAI
и пишет ответ прямо в чат с ботом:

* **есть описание** → сообщение строится вокруг этого описания, цепляется за конкретную деталь;
* **описания нет** (только возраст и город) → генерируется «красивое письмо», которое цепляет само по себе;
* **язык ответа = язык анкеты** (ru / uz / en определяются автоматически).

Схема одной анкеты:

```
Дайвинчик присылает фото с подписью «Имя, 24, Ташкент – описание»
      ↓ парсинг подписи (matcher/parser.py)
      ↓ сохранение анкеты в БД (matcher/services.py)
      ↓ генерация текста в OpenAI (matcher/ai.py + matcher/prompts.py)
      ↓ жмёт кнопку «лайк с сообщением» 💌 → ждёт «Отправь текст, видео или голосовое(до 15сек).»
      ↓ отправляет сгенерированный текст (с имитацией набора)
      ↓ бот переспрашивает «Отправить это сообщение пользователю?» → жмём 💌
Дайвинчик: «Лайк отправлен, ждем ответа» → показывает следующую анкету
```

## Важно перед запуском

* Дайвинчик — это **бот**, а Telegram Bot API не даёт одному боту читать сообщения другого.
  Поэтому здесь используется **юзербот**: вход по вашему номеру телефона через Telethon.
  Файл `data/davinchi.session` — это фактически доступ к вашему аккаунту, не коммитьте его и не передавайте.
* Автоматизация аккаунта — против правил и Telegram, и самого Дайвинчика. Аккаунт могут
  ограничить. Поэтому в проекте по умолчанию стоят: дневной лимит, случайные паузы,
  имитация набора текста и авто-пауза, когда бот жалуется на частоту. Не выкручивайте лимиты вверх.
* **Скрипт не нажимает кнопки бота наугад.** Он умеет только то, что нужно для анкет:
  💌 (лайк с сообщением), 👎, подтверждение отправки и пункт меню «1 🚀». Реклама Premium,
  вопрос про узбекский язык и любые другие врезки — это стоп: скрипт пишет вам в «Избранное»
  «закрой этот экран сам» и ждёт. Как только анкеты снова пошли, работа продолжается
  автоматически, перезапускать ничего не надо. Кнопки со звёздами и оплатой не нажимаются
  никогда, даже случайно.
* Сначала гоняйте всё в режиме `--dry-run`: текст будет приходить вам в «Избранное», ничего не отправляется.

## Установка

```bash
cd "C:\Users\user\Desktop\Давинчи"
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`:

| Переменная | Где взять |
|---|---|
| `OPENAI_API_KEY` | platform.openai.com → API keys |
| `OPENAI_MODEL` | по умолчанию `gpt-6-luna`, можно поставить модель помощнее |
| `TG_API_ID`, `TG_API_HASH` | my.telegram.org → API development tools |
| `TG_PHONE` | ваш номер в формате `+998...` |
| `TG_TARGET_BOT` | `leomatchbot` (менять не нужно) |
| `TG_NOTIFY_CHAT` | `me` — уведомления придут вам в «Избранное» |
| `API_TOKEN` | пусто = REST API открыт локально; задайте строку, чтобы требовать заголовок `X-API-Token` |

Инициализация базы:

```bash
python manage.py migrate
python manage.py createsuperuser
```

## Запуск

**1. Проверить генерацию без Telegram** (бьёт по OpenAI, Telegram не трогает):

```bash
python manage.py test_generate
```

```bash
python manage.py test_generate --caption ",, 24, Ташкент – no words. just"
```

**2. Авторизоваться в Telegram** (один раз, спросит код из Telegram, при 2FA — пароль):

```bash
python manage.py login_telegram
```

**3. Прогон вхолостую** — анкеты читаются и обрабатываются, тексты приходят вам в «Избранное»:

```bash
python manage.py run_userbot --dry-run
```

**4. Боевой запуск:**

```bash
python manage.py run_userbot
```

```bash
python manage.py run_userbot --limit 10
```

**5. API и админка** (в отдельном окне):

```bash
python manage.py runserver
```

* админка — http://127.0.0.1:8000/admin/
* API — http://127.0.0.1:8000/api/

## REST API

| Метод и адрес | Что делает |
|---|---|
| `GET /api/profiles/` | анкеты; фильтры `?status=&city=&has_description=&q=` |
| `GET /api/profiles/{id}/` | одна анкета вместе с последним сгенерированным текстом |
| `POST /api/profiles/{id}/regenerate/` | сгенерировать новый вариант текста для анкеты |
| `GET /api/messages/` | все сгенерированные сообщения, `?status=sent\|draft\|failed` |
| `GET /api/logs/` | журнал событий юзербота, `?level=&event=` |
| `POST /api/parse/` | `{"caption": "..."} ` → разбор подписи анкеты |
| `POST /api/generate/` | сгенерировать текст по анкете (без отправки в Telegram) |
| `GET/PATCH /api/config/` | настройки бота на лету |
| `POST /api/pause/` | `{"minutes": 60}` — пауза, `0` — снять |
| `GET /api/stats/` | сводка: сколько анкет, сколько отправлено сегодня |
| `GET /api/health/` | может ли бот сейчас работать и почему нет |

Примеры:

```bash
curl -X POST http://127.0.0.1:8000/api/generate/ -H "Content-Type: application/json" -d "{\"raw_caption\": \"Аня, 24, Ташкент — люблю горы и кофе\"}"
```

```bash
curl -X PATCH http://127.0.0.1:8000/api/config/ -H "Content-Type: application/json" -d "{\"tone\": \"playful\", \"daily_limit\": 25}"
```

## Настройки бота (`/api/config/` или админка → «Настройки бота»)

| Поле | Смысл |
|---|---|
| `enabled` | главный выключатель |
| `auto_like` / `auto_send` | жать ❤️ и отправлять текст автоматически |
| `tone` | `warm` — тёплый и лёгкий, `romantic` — красивый и образный, `playful` — с юмором |
| `language` | `auto` — отвечать на языке анкеты (по умолчанию), либо жёстко `ru` / `uz` / `en` |
| `max_chars` | максимальная длина сообщения (по умолчанию 320) |
| `extra_instructions` | своя строчка в промпт, например «упоминай, что я из Бухары» |
| `daily_limit` | сколько сообщений в сутки максимум (по умолчанию 40) |
| `min_delay` / `max_delay` | разброс пауз перед действиями, сек |
| `min_age` / `max_age` / `city_filter` | анкеты вне фильтра получают 👎 и пропускаются |
| `use_vision` | отдавать фото анкеты в модель (дороже; по умолчанию выключено) |
| `paused_until` | пауза до указанного времени |

## Структура

```
config/          настройки Django, urls, wsgi/asgi
matcher/
  models.py      BotConfig (настройки), Profile (анкета), GeneratedMessage, ActionLog
  parser.py      разбор подписи анкеты + распознавание фраз Дайвинчика
  prompts.py     промпты: с описанием и без описания
  ai.py          вызов OpenAI, выбор языка, обрезка длины, ретраи
  services.py    лимиты, фильтры, дедупликация, сохранение, журнал
  views.py       REST API
  admin.py       админка
  management/commands/test_generate.py
userbot/
  runner.py      Telethon: события, состояние «жду текст», отправка
  management/commands/login_telegram.py
  management/commands/run_userbot.py
data/            SQLite, файл сессии Telegram, скачанные фото
logs/            davinchi.log
```

## Если что-то не работает

* **Анкеты не распознаются.** Дайвинчик иногда меняет формат подписи. Проверьте разбор:
  `POST /api/parse/` или посмотрите в админке журнал событий — там будут записи `unparsed`
  с исходным текстом. Правила разбора — `matcher/parser.py`.
* **Текст не отправляется, в журнале `send_failed`.** Значит, бот не прислал
  «Отправь текст, видео или голосовое(до 15сек).» — сравните реальную фразу с шаблонами
  `ASK_MESSAGE_PATTERNS` в `matcher/parser.py` и допишите свою.
* **Скрипт молчит, а в «Избранном» просьба закрыть экран.** Дайвинчик показывает рекламу
  или вопрос — откройте чат с ботом и нажмите нужную кнопку сами. Скрипт продолжит сам.
  В журнале это событие `needs_attention` / `waiting_for_user`.
* **Telegram просит код при каждом запуске.** Файл сессии не сохранился — проверьте путь
  `TG_SESSION` в `.env` и права на папку `data/`.
* **`cryptg` не ставится** (нужен компилятор) — это необязательная зависимость, она только
  ускоряет шифрование. Уберите её из `requirements.txt`, всё будет работать.
